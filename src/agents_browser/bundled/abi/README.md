# agents-browser ABI Specification

This directory defines the stable Application Binary & Behavioral Interface (ABI) for `agents-browser`.

- [MCP.md](MCP.md) — Protocol specifications, server lifecycle, and JSON-RPC structures.
- [TOOLS.md](TOOLS.md) — Complete tool catalog, arguments, and behaviors.
- [LAYOUT.md](LAYOUT.md) — Browser profile filesystem layouts and port handling.
- [PLATFORM.md](PLATFORM.md) — OS executable locations and launch flags.
- [WHY.md](WHY.md) — Architectural rationale (Zero-Node, Zero-Puppeteer).
